# DES-010 素材集の画面

## 文書情報

| 項目 | 内容 |
|---|---|
| 文書ID | DES-010 |
| ドキュメント種別 | 機能設計書 |
| 対象システム/機能 | SPA（`web/`）: 素材提供者の画面、運営の素材集の審査・取り下げ、チャンネルの画面の素材集の表示、利用ガイド |
| 承認者 | 開発者 |
| ステータス | 実装済 |
| 版 | 1.0 |

## 目的・背景

素材集の申請・機械審査・承認・公開・毎日の確認（[DES-007](DES-007-materials-review.md)〜[DES-009](DES-009-materials-publish.md)）を、素材提供者と運営が画面から使えるようにする。API-001 の操作をそのまま使い、API は変えない。

## 対応元ID（トレーサビリティ）

| 対応元ID | 内容 | 対応状況 |
|---|---|---|
| API-001 | 素材提供者の 9 件・運営の 10 件の操作、C-17（身元の確認）、C-18（使っているチャンネル）、C-19（機械審査の結果）、題材の地図・基準の当たり | 画面にする |
| DES-003 | チャンネル提供者の画面（鍵・申請・署名） | 同じ作りで素材提供者の画面を足す |
| DES-005 | 運営の審査の画面 | 同じ作りで素材集の審査を足す |

## 方針・決定事項

| No. | 判断 | 理由 |
|---|---|---|
| N-1 | **素材提供者の画面は、チャンネル提供者の画面に「素材集」のメニューを足す**（アカウントは共通、M-16）。素材提供者の役割がないアカウントには、「素材集」を開くと説明と「素材提供者として始める」のボタンを出す（`POST /api/publisher/roles/producer`） | 別の画面にすると、鍵や設定が 2 か所になる |
| N-2 | 素材集の画面: 一覧と登録、詳細（状態、公開中の版の要約、毎日の確認の不具合、使っているチャンネル、申請の一覧）、申請（ZIP を選ぶ → ブラウザで署名 → アップロード → 機械審査の結果を待って表示）、取り消し。機械審査の結果は `errors`・`external`（外部の素材ごと）・`inUse`（D-8）・`warnings`（利用許諾の縮小）を分けて出す | API-001 C-18・C-19 |
| N-3 | **素材集の署名はブラウザで行う**。チャンネルの `signPackage` と同じく、鍵のファイルを合言葉で開き、`collection-package` の `signature.json` を作る。署名の前に `collection.json` の `id`・`version`・`producer` を確かめる | チャンネルと同じ。秘密鍵をサーバーに送らない（DES-003） |
| N-4 | **運営の素材集の審査の画面**（`/review/collections/:collectionId/:submissionId`）: パッケージをブラウザで開き、素材ごとに中身を出す（テキストは本文、画像は表示、外部の音声・映像は `<audio>`・`<video>` で元の URL を再生）。題材（`about`）は位置を OpenStreetMap へのリンクで出す（地図は埋め込まない）。タグ・利用許諾・出典・書き起こしも並べる。審査待ちの一覧の素材集の行から開く | 審査基準の素材の項目（出典・写っているもの・書き起こし・地点の安全）を画面で確かめられるようにする。地図のライブラリは使わない |
| N-5 | 身元の確認（C-17）: 審査の画面で、アカウントが確認済みでなければ、承認の欄に「確認の方法」「確認した内容」を必須で出し、アカウントの表示名・連絡先を並べる。確認済みなら、記録（方法・日時）を出す | D-20 |
| N-6 | 運営の素材集の管理: チャンネル提供者（アカウント）の詳細に「素材集」の欄を足し、素材集の詳細（使っているチャンネル・毎日の確認の不具合・取り下げ）へ進める。取り下げはチャンネルと同じ欄（理由・重さ・版） | 運営向けの素材集の一覧の API はないので、アカウントから辿る |
| N-7 | チャンネルの画面（チャンネル提供者・運営）に、機械審査の `collections`（宣言した素材集ごとの解決の結果）と、承認済みの版の `appStage`・`minAppVersions` を出す。どのアプリの版も仮の大きな値のときは「この素材に対応したアプリが出るまで、アプリの一覧に出ません」と添える | チャンネル提供者が、なぜアプリに出ないかを分かるようにする（DES-007 J-9） |
| N-8 | 基準（`selectors`）がどの素材集に当たるかは、画面に出さない | 当たりの判定（タグ・地域・利用許諾・順番）を画面で組み立て直すことになる。要望が出たら考える |
| N-9 | 利用ガイド: `docs/guide/producer.md`（素材集の作り方: `collection.json` の書き方、外部の素材の置き方、署名と申請、使っているチャンネル、毎日の確認）を足し、`concepts.md` の図に素材集を足す | チャンネル提供者向けのガイドと同じ扱い |

## 未決事項・リスク

| No. | 内容 | 対応 |
|---|---|---|
| 1 | 外部の素材を審査の画面で再生すると、運営のブラウザが素材提供者のサーバーに直接つながる | 運営だけの操作で、散策者の位置は関係しない。気になる場合は、再生の前に「外部のサーバーにつながります」と出す |
| 2 | 素材提供者が `collection.json` を手で書くのは難しい | ガイドに見本を載せる。作成を手伝う道具は、要望が出たら考える |
